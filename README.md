# AI GAME · 沙漠对决（DUST DUEL）

一个参考《反恐精英 2》(CS2) 的 **3D 第一人称射击** 单机游戏。
三把武器：**沙漠之鹰 / AWM / AK-47**；一个 AI 对手，三种难度，可以反复对战。
**纯离线、无需安装、无需联网**——双击 `index.html` 就能玩。

> 画面为低多边形沙色写实风（dust2 风格），所有贴图、模型、音效均由代码实时生成，没有任何外部图片/音频/字体文件。
> 音效为 WebAudio 程序化合成，**模仿 CS2 的听感**（AK 清脆、沙鹰低沉、AWM 超音速长回声），不使用任何 CS2 原始素材。

---

## 一、怎么开始

1. 打开 `D:\ai game 2 cs2` 文件夹；
2. 双击 **`index.html`**（推荐 Edge / Chrome，需开启硬件加速）；
3. 进入主菜单，选难度 → 点击「开始对战」——游戏会自动 **全屏 + 锁定鼠标**，直接开始；
4. 也可以双击 **`启动游戏.bat`**，会自动用默认浏览器打开。

> 第一次点击后浏览器才会允许播放声音（浏览器安全策略），属正常现象。
> 按 `Esc` 暂停并释放鼠标，点击画面任意处即可继续。
> 全屏和鼠标锁定必须由用户点击触发，所以如果浏览器拦下了自动全屏，点一下游戏画面即可重新进入。

### 配置要求

- 系统：Windows 10/11；浏览器：Microsoft Edge / Google Chrome（较新版本，支持 WebGL）
- 显卡：Intel HD Graphics 620 级别核显即可（i5-7200U 笔记本可流畅运行）
- 显卡加速需开启：Edge → 设置 → 系统和性能 → 硬件加速
- 若画面卡顿：设置里把「渲染分辨率」调成 **自动** 或 **0.7×**（默认自动，会动态调整）

| 操作 | 按键 |
| --- | --- |

## 三、沉浸式全屏与鼠标锁定

- **自动全屏**：点「开始对战」、点击游戏画面或按 `F` 时，页面会请求全屏（Fullscreen API），同时调用 Pointer Lock 把鼠标锁进游戏并隐藏光标。
- **视角使用 `movementX / movementY`**：鼠标锁定后视角只跟随鼠标移动量，不再受光标坐标影响，鼠标永远不会移出画面。
- **触控板防误触**：鼠标被锁定时，双指滑动不会再触发浏览器的前进 / 后退；游戏进行中也会拦截滚轮缩放。
- **彻底禁用右键菜单**：整个页面已监听 `contextmenu` 并阻止默认行为，右键只会用于 AWM 开镜，不会弹出浏览器菜单。
- **暂停与恢复**：按 `Esc`（或退出全屏 / 失去鼠标锁定）会自动暂停；暂停后会显示「点击画面任意处继续」的遮罩，点击画面或「继续游戏」按钮会重新全屏并锁定鼠标。
- 全屏 / 锁定必须由用户手势触发：如果某次浏览器拒绝了自动请求，点击游戏画面即可重试。

## 四、武器（参考 CS2 参数与手感，做了游戏化平衡）

| 武器 | 类型 | 弹匣 | 伤害 | 特点 |
| --- | --- | --- | --- | --- |
| **沙漠之鹰** | 手枪 | 7 | 身体 58 / 爆头 155 | 单发高伤、后坐大、移动扩散大；站定两枪身体带走，瞄准再打 |
| **AWM** | 狙击枪 | 5 | 身体 112 / 爆头 300 | **右键开镜**（FOV 90→26）；**开镜后散布为 0，指哪打哪**、一枪身体致死；腰射散布很大；开镜移动慢、开枪后拉栓 1.45s |
| **AK-47** | 步枪 | 30 | 身体 33 / 爆头 110 | 全自动；前几发精准、连射有弹道爬升，需要压枪；点射爆头最稳 |

- **站定/急停时最准**；移动速度偏低且有惯性，移动、跳跃时屏幕扩散与腰射散布都很明显。
- AWM 开镜后子弹严格沿准星中心飞行（第一发也不受本发后坐力影响）；腰射则很不准。
- 爆头有金属「叮」的命中音效与命中标记；身体命中是闷响。
- 换弹、切枪、开镜都有独立音效；AWM 拉栓声明显。
- 游戏没有护甲系统（简化），所有伤害直接作用于 100 HP。

## 五、AI 对手与难度

对手只有一个人：**BOT**，一把 AK-47，会巡逻、找人、架枪、对枪、走位、换弹和撤退。
每局先到 **8 杀** 获胜；死亡后 **3 秒**复活，复活后有 **1.5 秒**出生保护。

| | 简单 | 普通 | 困难 |
| --- | --- | --- | --- |
| 描述 | 反应慢、枪法飘，适合熟悉地图 | 会走位会架枪，正常对枪水平 | 预瞄、急停、压枪，爆头率高 |
| 反应时间 | 0.55~0.75s | 0.30~0.42s | 0.14~0.22s |
| 瞄准误差 | 大 | 中 | 小 |
| 爆头倾向 | 8% | 22% | 40% |
| 视野 / 听声 | 28m / 14m | 40m / 22m | 55m / 30m |

- 结算界面显示比分、击杀/死亡/爆头/命中率/最高连胜，可「再来一局」或「更换难度」。
- 最佳战绩会保存在浏览器本地（`localStorage`），下次打开仍在。
- 想反复练枪：结算后点「再来一局」即可；要换难度点「更换难度」。

## 六、地图

一张原创的 dust2 风格 1v1 地图 **de_dust_duel**（约 40×36m）：

- **long（西侧长道）**：33m 长枪线，适合 AWM；
- **mid（中央中庭）**：15~25m 对枪区，有纪念碑、柱门和高台，适合 AK；
- **short（东侧集市街）**：货柜、摊位、遮阳棚组成的近战拐角，适合沙鹰；
- **flank（东侧绕后路）**：S 形矮墙，可绕后偷袭；
- 南北出生大厅 + 两个后室，4 组随机出生点，每处出生点都有掩体。

掩体之间的间距、长/中/近距离视线、绕后路线均经过数据校验，适合对枪节奏。

## 八、常见问题

**Q：打开后黑屏 / 提示 WebGL 初始化失败？**
A：请使用较新的 Edge/Chrome，并在浏览器设置里开启「硬件加速」；也可尝试更新显卡驱动。

**Q：没有声音？**
A：浏览器要求先在页面上点击一次（开始游戏会触发），并检查系统音量 / 浏览器标签页是否静音；按 `M` 可切换静音。

**Q：卡顿 / 掉帧？**
A：设置 → 渲染分辨率选「自动」（默认），或手动 0.7×/0.55×；关闭其他占用核显的程序；确保笔记本插电且电源模式为「高性能」。

**Q：触控板滑动/双指手势会触发浏览器前进、后退？**
A：开始对战并进入全屏+鼠标锁定后，手势不会再触发浏览器导航；如果已经退回暂停菜单，点击画面继续即可重新锁定。

**Q：右键还是弹出浏览器菜单？**
A：页面已全局监听 `contextmenu` 并禁止默认菜单，右键只用于 AWM 开镜。如果仍有菜单，说明鼠标锁定没有生效，点击一下游戏画面重新进入沉浸模式。

**Q：自动全屏没有触发 / 全屏被浏览器拦下？**
A：全屏和鼠标锁定必须由用户点击触发。点击「开始对战」、点击游戏画面或按 `F` 都可以重新请求；若浏览器策略仍然拦截，请检查是否处于 iframe 中，或换用 Edge / Chrome 打开本地 `index.html`。

**Q：鼠标锁定后怎么退出？**
A：按 `Esc` 会暂停并释放鼠标与全屏；点击画面任意处或「继续游戏」按钮会重新全屏并锁定。

**Q：能改键吗？**
A：当前版本键位固定；可在设置里实时调整鼠标灵敏度、主音量、渲染分辨率和准星颜色。灵敏度默认 1.00，建议 0.8~1.2。

**Q：对手太强 / 太弱？**
A：主菜单或结算界面切换难度。困难 BOT 会预瞄和急停，建议用 AWM 架长道、AK 中距离点射、沙鹰守拐角。
